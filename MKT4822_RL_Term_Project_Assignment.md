## 1. General Project Objective

In this project, you must improve only the **reinforcement-learning-related decision mechanism** of the provided local LLM coding-agent repository. The system generates `algorithm.py` from a natural-language task and then runs automatic validation and runtime checks.

The objective of this assignment is not to modify the LLM model, validation system, agent loop, or benchmark infrastructure. Your task is only to work on the permitted RL files and improve how the agent chooses generation strategies in different contexts.

For any case not explicitly defined in this document, interpretation, implementation, and final evaluation authority belongs to the instructor. Submission validity, scope violations, originality, group contribution, technical error handling, and grading interpretation are determined by the instructor.

## 11. Proof Runs in a Temporary Workspace

Students must not perform proof runs by manually adding `algorithm.py` into the repository root. Proof runs must be performed in a temporary workspace (for example under `runs/`).

For testing, only the learning method may be changed in config, and learning may be enabled.

This means in temporary workspace config, `learning.mode` may be changed and `learning.enabled: true` may be set. Other config behavior must remain aligned with project defaults. This does not mean changing repository main config files; it applies only to temporary evaluation workspaces.

Example workspace config logic:

```yaml
repo:
  target_file: algorithm.py

agent:
  max_repairs: 3

memory:
  path: .mecha-agent/memory.sqlite

direct:
  request_timeout_sec: 600

learning:
  enabled: true
  mode: "thompson"
  persist: true
```

## 12. Experimental Comparison

Each group must compare at least the following three systems:

```text
A0: baseline with learning disabled
A1: instructor-provided starter repository with the task text from `project-assignment/mkt4822_actor_critic.txt`
A2: the group's improved RL structure
```

Minimum required metrics:

```text
success_rate
runtime_pass_rate
mean_attempts
mean_reward
mean_duration_sec
Distribution of syntax_fail / import_fail / runtime_fail / behavior_fail / other_fail
```

Metric definitions (mandatory):

```text
success_rate = successful validations / total run count
runtime_pass_rate = runtime-pass count / total run count
mean_attempts = average attempts per run
mean_reward = average final reward per run
mean_duration_sec = average wall-clock seconds per run
failure distribution = counts of syntax_fail, import_fail, runtime_fail, behavior_fail, other_fail
```

Fairness protocol (mandatory):

```text
All official grading runs (A0, A1, A2, and final check) are executed on the instructor's own computer.
The same machine and environment settings must be used across A0/A1/A2.
Student local results are informative only and are not solely authoritative for grading.
```

General benchmark command:

```bash
python scripts/hard_runtime_benchmark.py   --backend ollama   --mode both   --max-attempts 6   --repeat 3   --out runs/student_benchmark.jsonl   --workspaces-dir runs/student_workspaces
```

The fake backend is for smoke testing only and is not sufficient as final performance evidence:

```bash
python scripts/hard_runtime_benchmark.py   --backend fake   --mode both   --max-attempts 2   --repeat 1   --out runs/fake_smoke.jsonl   --workspaces-dir runs/fake_smoke_workspaces
```

## 18. MKT4822 Proof Run Example

The following example is provided for local proof runs. Do not modify repository main config files; enable learning in a temporary workspace.

```bash
TASK="$(cat project-assignment/mkt4822_actor_critic.txt)"
WORKSPACE="runs/mkt4822_proof_workspace"

mecha-agent init "$WORKSPACE" --force

cat > "$WORKSPACE/configs/default.yaml" <<'YAML'
repo:
  target_file: algorithm.py

agent:
  max_repairs: 3

memory:
  path: .mecha-agent/memory.sqlite

direct:
  request_timeout_sec: 600

learning:
  enabled: true
  mode: "thompson"
  persist: true
YAML

mecha-agent run "$TASK"   --path "$WORKSPACE"   --max-attempts 6   --judge-final | tee "$WORKSPACE/run_output.txt"

mecha-agent validate   --path "$WORKSPACE"   --task "$TASK" | tee "$WORKSPACE/validate_output.txt"
```

Required proof outputs:

```text
runs/mkt4822_proof_workspace/algorithm.py
runs/mkt4822_proof_workspace/generation_report.csv
runs/mkt4822_proof_workspace/run_output.txt
runs/mkt4822_proof_workspace/validate_output.txt
```

For submission, you may copy `algorithm.py` as `proof/generated_algorithm.py`. This file must not be manually edited.
